# 4Sum [Problem Link: https://leetcode.com/problems/4sum/](https://leetcode.com/problems/4sum/)

---

# 1. Problem Explanation

Given an integer array `nums` and an integer `target`, return all **unique quadruplets**:

[nums[a], nums[b], nums[c], nums[d]]

Such that:

- 0 ≤ a, b, c, d < n
- All indices are distinct
- nums[a] + nums[b] + nums[c] + nums[d] = target

The result can be returned in any order.

### Example 1
Input: nums = [1,0,-1,0,-2,2], target = 0  
Output: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

### Example 2
Input: nums = [2,2,2,2,2], target = 8  
Output: [[2,2,2,2]] 

Explanation

```

-2 + -1 + 1 + 2 = 0
-2 + 0 + 0 + 2 = 0
-1 + 0 + 0 + 1 = 0

```

# 3. Approaches

---

# Approach 1: Brute Force

### Idea

Try every possible combination of four elements.

Use **four nested loops**.

Check if their sum equals target.

Store valid quadruplets while avoiding duplicates.

---

### Algorithm

1. Iterate `i` from `0 → n-4`
2. Iterate `j` from `i+1 → n-3`
3. Iterate `k` from `j+1 → n-2`
4. Iterate `l` from `k+1 → n-1`
5. Check if sum equals target
6. Store quadruplet

---

### Java Implementation

```java
import java.util.*;

class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {

        int n = nums.length;
        Set<List<Integer>> set = new HashSet<>();

        Arrays.sort(nums);

        for(int i = 0; i < n - 3; i++){
            for(int j = i + 1; j < n - 2; j++){
                for(int k = j + 1; k < n - 1; k++){
                    for(int l = k + 1; l < n; l++){

                        long sum = (long)nums[i] + nums[j] + nums[k] + nums[l];

                        if(sum == target){
                            set.add(Arrays.asList(nums[i], nums[j], nums[k], nums[l]));
                        }
                    }
                }
            }
        }

        return new ArrayList<>(set);
    }
}
````

---

### Time Complexity : `O(n^4)`

### Space Complexity `O(m)  (m = number of unique quadruplets)`

# Approach 2: Optimal Approach (Sorting + Two Pointer)

### Core Idea

Reduce the **4Sum problem into 2Sum**.

Steps:

```
1. Sort the array
2. Fix first element
3. Fix second element
4. Solve remaining using two pointers
```

---

### Algorithm

1. Sort the array.
2. Loop `i` from `0 → n-4`.
3. Skip duplicates for `i`.
4. Loop `j` from `i+1 → n-3`.
5. Skip duplicates for `j`.
6. Use two pointers:

   ```
   left = j + 1
   right = n - 1
   ```
7. Compute sum:

   ```
   nums[i] + nums[j] + nums[left] + nums[right]
   ```
8. Adjust pointers:

   * If sum == target → store result
   * If sum < target → move left++
   * If sum > target → move right--
9. Skip duplicates for left and right.

---

### Java Implementation

```java
import java.util.*;

class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {

        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;

        if(n < 4) return result;

        Arrays.sort(nums);

        for(int i = 0; i < n - 3; i++){

            if(i > 0 && nums[i] == nums[i - 1]) continue;

            for(int j = i + 1; j < n - 2; j++){

                if(j > i + 1 && nums[j] == nums[j - 1]) continue;

                int left = j + 1;
                int right = n - 1;

                while(left < right){

                    long sum = (long)nums[i] + nums[j] + nums[left] + nums[right];

                    if(sum == target){

                        result.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));

                        left++;
                        right--;

                        while(left < right && nums[left] == nums[left - 1])
                            left++;

                        while(left < right && nums[right] == nums[right + 1])
                            right--;
                    }
                    else if(sum < target){
                        left++;
                    }
                    else{
                        right--;
                    }
                }
            }
        }

        return result;
    }
}
```

---

### Time Complexity

```
Sorting → O(n log n)

Main loops → O(n^3)

Total → O(n^3)
```

---

### Space Complexity

`
O(1) (excluding output list)
`

# 4. Important Interview Points

### 1️⃣ Sorting is mandatory

Sorting allows:

```
Two pointer movement
Duplicate removal
Predictable sum behavior
```

---

### 2️⃣ Duplicate Handling

Duplicates must be skipped at **four places**:

```
First loop (i)
Second loop (j)
After moving left
After moving right
```

Otherwise duplicate quadruplets appear.

---

### 3️⃣ Integer Overflow

Large numbers may overflow `int`.

Example:

```
10^9 + 10^9 + 10^9 + 10^9
```

Use:

```
long sum
```

---

### 4️⃣ Generalization (K-Sum)

This solution follows **K-Sum pattern**:

```
Fix K-2 numbers
Solve remaining using Two Pointer
```

Used in many interview problems.

---

### 5️⃣ Edge Cases

* Array length < 4
* Large integers causing overflow
* All elements same
* No valid quadruplet
